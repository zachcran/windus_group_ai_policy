# Windus Group AI Policy Repo

This repository aims to provide a collaborative space for the Windus Group to propose and craft a group-wide AI policy.

## Interacting with the Repo

- Be respectful, AI usage can be a heated topic
- Use Markdown for text when possible ([basic syntax here](https://commonmark.org/help/))
- Clone the repo to your computer or use the website's interface to make edits
- Use [branches](https://docs.github.com/en/pull-requests/reference/branches)+[pull requests](https://docs.github.com/en/pull-requests/reference/pull-requests) or a [fork](https://docs.github.com/en/pull-requests/reference/forks)+pull requests to contribute suggestions/changes and open discussions that may result in additions (ask someone more senior if you don't know how!)

## Contents

- `policy.md` - Policy draft
- `docs/` - Supplementary documents that provide more context, notes from discussions, links to useful articles, etc.

- `docs/crandall_how_i_use_ai_in_programming.md` - Transcription of Zach's slides from Aug 21, 2026 that somewhat kicked off the group policy discussion.
