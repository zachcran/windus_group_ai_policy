# Windus Group AI Policy Repo

This repository aims to provide a collaborative space for the Windus Group to propose and craft a group-wide AI policy. Please keep in mind that the contents of this repository are a work in progress and at this moment the policy is a shifting and evolving document.

## Interacting with the Repo and Other Contributors

- Be respectful, AI usage can be a heated topic
- Use Markdown for text whenever possible ([basic syntax here](https://commonmark.org/help/))
- [Open an issue](https://github.com/zachcran/windus_group_ai_policy/issues/new) if you want to start a general discussion about an aspect of the policy

## Contributing

- [Clone](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) the repo to your computer or directly through GitHub's web interface.
- [Open an issue](https://github.com/zachcran/windus_group_ai_policy/issues/new) to discuss major changes first. This helps ensure that you don't waste your time with changes that have a high likelihood of being rejected.
- Propose changes using [branches](https://docs.github.com/en/pull-requests/reference/branches)+[pull requests](https://docs.github.com/en/pull-requests/reference/pull-requests) or [forks](https://docs.github.com/en/pull-requests/reference/forks)+pull requests (ask someone more experienced in the group if you don't know how!).

**Regarding external input:** We are not currently accepting pull requests from external groups. We allow suggestions via issues from external groups, but reserve the right to reject any suggestions.

## Contents

- `policy.md` - Policy draft
- `docs/` - Supplementary documents that provide more context, notes from discussions, links to useful articles, etc.

- `docs/crandall_how_i_use_ai_in_programming.md` - Transcription of Zach's slides from Aug 21, 2026 that somewhat kicked off the group policy discussion.
