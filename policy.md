# Windus Group AI Policy

## Rules

- You are responsible for the end product, regardless of whether AI was involved or not.
- Do not submit an AI-generated product for review from someone else until you have reviewed it yourself.
- Do not expose your work or data to AI systems that do not have strict assurances on data privacy. These tools often train on information provided to them, which may expose sensitive information like IP or PII.

## Guidelines

- As with all new technologies, AI should be used carefully and mindfully.
- Plan and be intentional about when and how you apply AI for a task.
- It is important to learn how to write effective prompts. Take the time to learn the basics of prompting (see `tips/prompting.md`).

### Software Development

- In software, you need to be the driver in the architecture/design. Until you are at least an intermediate-level programmer, only have AI generate code that you know how to write yourself. Motivation: AI is terrible at architecture. It is difficult to be a good architect if you do not have a feel for how the underlying code should look.
- If the AI generates code you don't understand, ask the AI to explain the code. Don't forget to ask for pictures and equations when it makes sense! Similarly, if the AI generates code that doesn't line up with what you envisioned, ask it how you could improve the original design document.
