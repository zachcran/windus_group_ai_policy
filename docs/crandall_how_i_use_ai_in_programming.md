## Safety

- Do not allow agents to run on systems with sensitive information – Use virtual machines or containers
- Make sure you have backups before it makes changes
- Verify what the AI claims; they will lie, but usually fold immediately upon challenge

## Tips for Use

- Treat the AI like a junior developer – it has technical skill, but is clueless about the big picture
- It is a tool, not a replacement for you knowing what you are doing
- Maintain some human component that you are actively doing to actually understand what is going on with your program (changelog or comments)
- Don’t let the AI lead you!

## Prompting

- Use Markdown; this is the “language of AI”
- “Ask me if you have any questions and do not take action until everything is clear.”
- Provide links and point to useful context
- Planning mode is great!
